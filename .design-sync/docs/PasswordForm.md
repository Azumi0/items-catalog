# PasswordForm

Changing an existing account's password. A teal note names whose password this
is — the screen is reached from another person's card, so saying so matters —
over a single "Nowe hasło" field. Ships from the same module as `UserForm`.

```jsx
<PasswordForm user={{ id: 'u-2', username: 'piotr' }} />
```
